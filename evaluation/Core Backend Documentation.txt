CACHE.PY DOCUMENTATION
====================

Overview
--------
This module provides a centralized caching system for managing different types of data
in the Open Greek Financial LLM Leaderboard. It handles caching for datasets, models,
votes, and evaluation data using a structured directory system.

Dependencies
-----------
- pathlib.Path: For cross-platform path handling
- datetime.timedelta: For cache expiration timing
- logging: For operation logging
- shutil: For directory operations
- os: For environment variable management

Configuration
------------
Required environment variables:
- HF_HOME: Root directory for HuggingFace cache
- TRANSFORMERS_CACHE: Directory for model cache
- HF_DATASETS_CACHE: Directory for dataset cache

Class: CacheConfig
-----------------
Manages the caching system for the Open Greek Financial LLM Leaderboard.
Implements a singleton pattern to ensure consistent cache management across the application.

Cache Types:
- Datasets: For HuggingFace dataset storage
- Models: For model files and configurations
- Votes: For user voting data
- Evaluation: For model evaluation results

Attributes:
- cache_root (Path): Root directory for all caches
- datasets_cache (Path): Directory for dataset cache
- models_cache (Path): Directory for model cache
- votes_cache (Path): Directory for votes cache
- eval_cache (Path): Directory for evaluation cache
- votes_file (Path): Path to votes data file
- eval_requests_file (Path): Path to evaluation requests file
- cache_ttl (timedelta): Time-to-live for cached data

Methods
-------

1. __init__()
   Purpose: Initialize the cache configuration system
   Actions:
   - Defines cache paths from configuration
   - Sets up specific file paths for votes and evaluations
   - Configures cache expiration time
   - Initializes cache directories
   - Sets up environment variables
   Raises: Exception if directory creation fails

2. _initialize_cache_dirs()
   Purpose: Create all necessary cache directories
   Directory Structure:
   cache_root/
   ├── datasets/    # For HuggingFace datasets
   ├── models/      # For model files
   ├── votes/       # For voting data
   └── eval/        # For evaluation data
   Raises: Exception if directory creation fails

3. _setup_environment()
   Purpose: Configure HuggingFace environment variables for caching
   Sets up:
   - HF_HOME: Root directory for HuggingFace cache
   - TRANSFORMERS_CACHE: Directory for model cache
   - HF_DATASETS_CACHE: Directory for dataset cache

4. get_cache_path(cache_type: str) -> Path
   Purpose: Get the path for a specific cache type
   Args:
   - cache_type (str): Type of cache to get path for
     Valid values: "datasets", "models", "votes", "eval"
   Returns: Path to the requested cache directory
   Note: Returns cache_root if cache_type is not recognized

5. flush_cache(cache_type: str = None)
   Purpose: Clear specified cache or all caches
   Args:
   - cache_type (str, optional): Type of cache to clear
     If None, clears all caches
     Valid values: "datasets", "models", "votes", "eval"
   Actions:
   - Removes all files in the specified cache directory
   - Recreates the directory structure
   - Logs the operation details
   Raises: Exception if cache clearing fails

FASTAPI_CACHE.PY DOCUMENTATION
==============================

Overview
--------
This module provides a caching system for FastAPI endpoints in the Open Greek Financial LLM Leaderboard.
It implements an in-memory caching solution with configurable expiration times and key management.

Dependencies
-----------
- fastapi_cache: Core caching functionality
- fastapi_cache.backends.inmemory: In-memory cache backend
- fastapi_cache.decorator: Caching decorators
- datetime.timedelta: For time-based cache expiration
- logging: For operation logging

Configuration
------------
Required environment variables:
- CACHE_TTL: Time-to-live for cached responses in seconds

Functions
---------

1. setup_cache()
   Purpose: Initialize the FastAPI caching system
   Actions:
   - Sets up in-memory backend
   - Configures cache prefix
   - Sets default expiration time
   - Logs initialization status
   Usage:
   ```python
   setup_cache()
   ```

2. invalidate_cache_key(key: str)
   Purpose: Remove a specific item from the cache
   Args:
   - key (str): The cache key to invalidate
   Actions:
   - Attempts to delete the specified key
   - Logs success or failure
   - Handles backend compatibility
   Usage:
   ```python
   invalidate_cache_key("my-cache-key")
   ```

3. build_cache_key(namespace: str, *args) -> str
   Purpose: Create a consistent cache key
   Args:
   - namespace (str): Namespace for the cache key
   - *args: Additional arguments to include in the key
   Returns:
   - str: Formatted cache key
   Format: "fastapi-cache:{namespace}:{args}"
   Usage:
   ```python
   key = build_cache_key("models", "status", "all")
   ```

4. cached(expire: int = CACHE_TTL, key_builder=None)
   Purpose: Decorator for caching endpoint responses
   Args:
   - expire (int): Cache expiration time in seconds
   - key_builder (callable, optional): Custom key builder function
   Returns:
   - Decorator function for caching
   Usage:
   ```python
   @cached(expire=300)
   async def get_models():
       return await model_service.get_models()
   ```

Cache Key Structure
-----------------
Format: "fastapi-cache:{namespace}:{args}"
Example: "fastapi-cache:models:status:all"

Components:
1. Prefix: "fastapi-cache"
2. Namespace: Identifies the type of data
3. Arguments: Additional identifiers

Example Usage
------------

1. Basic Caching:
   ```python
   @cached(expire=300)
   async def get_leaderboard():
       return await leaderboard_service.get_data()
   ```

2. Custom Key Building:
   ```python
   def custom_key_builder(func, namespace: str, **kwargs):
       return f"custom:{namespace}:{kwargs.get('user_id')}"

   @cached(key_builder=custom_key_builder)
   async def get_user_data(user_id: str):
       return await user_service.get_data(user_id)
   ```

3. Cache Invalidation:
   ```python
   async def update_model(model_id: str):
       await model_service.update(model_id)
       invalidate_cache_key(build_cache_key("models", model_id))
   ```
